# SwiftSend Build Progress Form

A form for tracking SwiftSend build progress: project & team info, countries, overall status, deliverables (Kenya Corridor & Stellar Anchor, USSD Pilot, Kenya Corridor Validation, Evidence & Pilot Report), budget, 30-day timeline, evidence checklist, next steps, out of scope and constraints.

- **HTML form** — `SwiftSend-Build-Progress-Form.html` (interactive, saves as JSON)
- **Markdown form** — `SwiftSend-Build-Progress-Form.md` (fillable on any markdown viewer)

Fill in the spaces (the underscore lines) with your sentences.
